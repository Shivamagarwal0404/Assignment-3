## Task 1: Calculate Factorial Using a Function

### Description

This program defines a function named `factorial` that calculates the factorial of a number using recursion. The function takes a number as an argument and returns the factorial value.

### Features

* Uses a user-defined function
* Uses recursion
* Handles base cases (0 and 1)
* Returns and prints factorial result

### Example

Input:

```
Enter the number: 5
```

Output:

```
Factorial is: 120
```

### File

```
factorial.py
```

## Task 2: Using the Math Module for Calculations

### Description

This program uses the built-in Python `math` module to perform mathematical calculations on a number entered by the user.

### Calculations performed:

* Square root
* Natural logarithm (log base e)
* Sine (in radians)

### Example

Input:

```
Enter a number: 25
```

Output:

```
Square root: 5.0
Natural logarithm: 3.2188758248682006
Sine: -0.13235175009777303
```

### File

```
math_calculations.py
```
